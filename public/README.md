# 大喜利バトル プロトタイプ

## 起動方法

```bash
npm install
npm start
```

ブラウザで開くURL:

```text
http://localhost:3000
```

## 今回入っている機能

- アカウント新規登録
- ログインID・パスワードログイン
- 表示名変更
- ユーザーIDごとの戦績保存
- Elo風レーティング
- トロフィーランキング
- 部屋作成・参加
- 最大10人部屋
- ルーレット式お題担当
- 3分回答、1分投票
- 通報退出
- 2回通報退出で1週間ログイン制限

## 保存先

```text
data/stats.json
```

このファイルにユーザー情報と戦績が保存されます。ローカル試作用なので、パスワードはハッシュ化していますが、本番公開する場合はDBとセッション管理に移行してください。

## 追加された機能

- 部屋一覧表示
- 待機中の部屋への参加ボタン
- クイック参加
- 部屋退出ボタン
- 開始済み部屋は参加不可表示
